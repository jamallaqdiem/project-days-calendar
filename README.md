# project-days-calendar# Days Calendar

# What this is

A small web app that shows special commemorative days which don’t happen on the same date every year (for example: second Tuesday of a month). The app works out the correct date and displays it in a calendar.

# Run it

- Clone the repo
- Open the folder
- Open `index.html` in your browser
